# Project Instructions

## At the start of every new conversation
Read `PROJECT_CONTEXT.md` to load the current state of the project, ongoing work, and relevant background. Update it as the project state evolves so future conversations have an accurate picture.

## When making a fix
Whenever you make a code or config change intended to fix a bug or debug an issue, append an entry to `FIXES_ATTEMPTED.md` describing:
- What you are trying to fix
- The hypothesis behind the change
- The expected effect / how to tell if it worked

Read `FIXES_ATTEMPTED.md` before attempting a new fix so you don't repeat approaches that have already been tried.
